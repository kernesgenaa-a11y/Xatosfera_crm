<title>Фільтри в URL (query params) — збереження стану</title>
<description>
## Контекст

Фільтри на сторінках PropertiesPage, ClientsPage, DealsPage зберігаються тільки в React state. При refresh або share URL — фільтри скидаються.

## Файли

* **Створити:** `src/hooks/useUrlFilters.ts` (custom hook)
* **Змінити:** `src/pages/PropertiesPage.tsx`
* **Змінити:** `src/pages/ClientsPage.tsx`
* **Змінити:** `src/pages/DealsPage.tsx`
* **Змінити:** `src/pages/NotesPage.tsx`

## Кроки

1. Створити `src/hooks/useUrlFilters.ts`:

   ```ts
   import { useSearchParams } from 'react-router-dom';
   
   export function useUrlFilters<T extends Record<string, string>>(defaults: T) {
     const [searchParams, setSearchParams] = useSearchParams();
     
     const filters = useMemo(() => {
       const result = { ...defaults };
       for (const key of Object.keys(defaults)) {
         const value = searchParams.get(key);
         if (value) result[key] = value;
       }
       return result;
     }, [searchParams, defaults]);
     
     const setFilter = useCallback((key: string, value: string) => {
       setSearchParams(prev => {
         if (value === defaults[key] || !value) prev.delete(key);
         else prev.set(key, value);
         return prev;
       });
     }, [setSearchParams, defaults]);
     
     return { filters, setFilter, setSearchParams };
   }
   ```
2. У `PropertiesPage.tsx` замінити `useState` фільтрів на `useUrlFilters()`:

   ```ts
   // БУЛО:
   const [status, setStatus] = useState('all');
   const [type, setType] = useState('all');
   
   // СТАЛО:
   const { filters, setFilter } = useUrlFilters({ status: 'all', type: 'all', search: '' });
   ```
3. Повторити для ClientsPage, DealsPage, NotesPage
4. URL виглядатиме як: `/properties?status=active&type=apartment&search=центр`

## НЕ робити

* Не зберігати фільтри в localStorage
* Не використовувати state management (Redux, Zustand)

## Acceptance Criteria

- [ ] Фільтри відображаються в URL query params
- [ ] При refresh сторінки фільтри зберігаються
- [ ] При copy/paste URL — відкривається з тими ж фільтрами
- [ ] Очищення фільтра видаляє його з URL
- [ ] `npm run build` проходить
- [ ] Працює для properties, clients, deals, notes
