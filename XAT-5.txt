<title>Додати rate-limiting для auth endpoints</title>
<description>
## Контекст

`/api/auth/login` та `/api/auth/register` не мають rate-limiting — brute-force можливий.

## Файли

* **Змінити:** `worker/src/auth.ts`, `worker/src/index.ts`
* **Залежність:** XAT-6 (реструктуризація бекенду)

## Кроки

1. Створити `worker/src/middleware/rate-limiter.ts`
2. Реалізувати rate limiter на D1 (таблиця `rate_limits`):

   ```sql
   CREATE TABLE rate_limits (key TEXT PRIMARY KEY, count INTEGER, window_start INTEGER);
   ```
3. Ключ: `rate:{ip}:{endpoint}`
4. Ліміти:
   * `/api/auth/login` — 5 спроб / 15 хвилин
   * `/api/auth/register` — 3 спроби / 1 годину
5. При перевищенні: `429 Too Many Requests` + `Retry-After` header
6. Успішний логін скидає лічильник для цього IP

## Acceptance Criteria

- [ ] 6-й запит login з одного IP за 15 хв → 429
- [ ] 4-й запит register з одного IP за годину → 429
- [ ] Відповідь 429 містить `Retry-After`
- [ ] Успішний логін скидає лічильник
- [ ] Різні IP не впливають один на одного
</description>

<title>Налаштувати CI/CD (GitHub Actions)</title>
<description>
## Контекст

CI/CD повністю відсутній — немає GitHub Actions, немає автоматичного деплою.

## Файли

* **Створити:** `.github/workflows/ci.yml`
* **Створити:** `.github/workflows/deploy.yml` (опціонально)

## Кроки

1. Створити `.github/workflows/ci.yml` з jobs:

   ```yaml
   name: CI
   on: [push, pull_request]
   jobs:
     lint:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v4
         - uses: actions/setup-node@v4
           with: { node-version: 20 }
         - run: npm ci
         - run: npm run lint
     typecheck:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v4
         - uses: actions/setup-node@v4
           with: { node-version: 20 }
         - run: npm ci
         - run: npx tsc --noEmit
     test:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v4
         - uses: actions/setup-node@v4
           with: { node-version: 20 }
         - run: npm ci
         - run: npm run test
     build:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v4
         - uses: actions/setup-node@v4
           with: { node-version: 20 }
         - run: npm ci
         - run: npm run build
   ```
2. Переконатися що `npm run lint`, `npx tsc --noEmit`, `npm run test`, `npm run build` проходять локально перед пушем

## НЕ робити

* Не додавати deploy step без секретів Cloudflare
* Не модифікувати існуючий код щоб пройти CI — тільки створити workflow

## Acceptance Criteria

- [ ] `.github/workflows/ci.yml` існує
- [ ] Workflow запускається на push та PR
- [ ] Jobs: lint, typecheck, test, build — всі проходять
- [ ] PR в GitHub показує статус CI checks
